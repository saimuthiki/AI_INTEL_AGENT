## This week's biggest story

This week was defined by two parallel surges that together signal a clear inflection point for RAG and agentic systems. For teams building RAG pipelines with agents on top, the message is unambiguous: the orchestration layer is no longer research-grade. You need to pick a production framework this week or get left behind.

**[Paper] A-RAG: Scaling Agentic Retrieval-Augmented Generation via Hierarchical Retrieval Interfaces**
- Source: arXiv + GitHub trending + AIToolly + AgenticRAG-Survey
- TL;DR: Introduces three-tier agentic retrieval — keyword_search, semantic_search, chunk_read — exposed as tools to an LLM agent. The agent adaptively chooses which retrieval granularity to use per sub-question. Outperforms BM25+DPR baselines on HotpotQA and MuSiQue multi-hop QA. Code released on GitHub.
- Key contribution: First to show that giving the LLM direct control over retrieval granularity (not just what to retrieve, but how) significantly improves multi-hop accuracy without increasing retrieved token count.
